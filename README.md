# СТУ-Нормоконтроль

Сайт для проверки документов Word по стандарту **СТУ 7.5–07–2021** (СФУ).
Работает локально в браузере, ничего устанавливать не нужно.

Закидываете файл `.docx`, а сайт показывает его постранично, с полями,
отступами, списками, таблицами, рисунками и колонтитулом, и подсвечивает
ошибки оформления. Слева список замечаний с рекомендациями, справа список
листов.

Титульный лист не проверяется и не изменяется: по нему только определяется вид
работы (курсовая, дипломная, отчёт по практике, ВКР, реферат и другие).

## Как скачать и запустить

### Windows

1. Кнопка **Code → Download ZIP**, распакуйте архив.
2. Откройте `index.html` двойным щелчком (Chrome, Firefox или Edge).

Или через Git:

```
git clone https://github.com/99VP/SFU-format-control.git
```

### Linux

1. Кнопка **Code → Download ZIP** и распакуйте, или в терминале:

```
git clone https://github.com/99VP/SFU-format-control.git
cd stu-normokontrol
```

2. Откройте:

```
xdg-open index.html
```

## Как пользоваться

1. Перетащите файл `.docx` в окно или выберите его на диске.
2. Вид документа определится сам. Если неверно, нажмите нужный вид, документ
   перепроверится сразу.
3. Нажмите на замечание слева, чтобы перейти к месту в документе.
4. Сверху линейка: ноль у границы текста, метка отступа 12,5 мм.

Полезно:

- Последний файл сохраняется в браузере, после обновления страницы он
  проверится заново.
- Новый файл можно просто перетащить в окно.
- История проверок хранится локально (до 5 записей, можно развернуть).
- Поддерживаются файлы `.docx`, `.doc` (через сервер) и `.pdf` (просмотр страниц).
- Кнопка **PDF** сохраняет развёртку в готовый pdf-файл.
- Панели «Замечания» и «Листы» можно свернуть.

## Исправление .docx

Кнопка **«Исправить .docx»** собирает исправленный файл и скачивает его.
Word открывает его штатно. Меняется только `word/document.xml`, всё остальное
сохраняется. Титульный лист не затрагивается.

Можно выбрать, что исправить: шрифт, выравнивание, абзацный отступ,
межстрочный интервал, формат А4 и поля, тире в диапазонах чисел.

## Что проверяется

Поля и формат листа, шрифт и абзац, структура документа, заголовки, нумерация
страниц, выделения в тексте, перечисления, формулы, таблицы, рисунки, ссылки и
список источников, список сокращений, пунктуация, а также типографика и следы
машинного текста (невидимые пробелы, разметка Markdown, метки чат-ботов и
подобное). Проверяются только структура и оформление, содержание работы не
оценивается.

## Старый формат .doc

Статический сайт читает только `.docx`. Для `.doc` есть необязательный сервер
(нужны Python 3 и LibreOffice):

```
python3 server/server.py
```

Затем откройте http://127.0.0.1:8777/ и загрузите `.doc`. Проще сохранить файл
как `.docx` в Word.

## Приватность и безопасность

Сайт работает локально, файлы никуда не отправляются. Текст документа выводится
безопасно, ничего из файла не исполняется. Внешние ссылки и картинки из
документа не загружаются.

- В проекте **нет** API-ключей, токенов и паролей: ни в коде, ни в истории git.
  Сайт не обращается к внешним сервисам, поэтому ключи ему не нужны.
- В `.gitignore` запрещено коммитить `.env`, `*.key`, `*.pem`, `*.keystore`,
  `keystore.properties` и файлы со словами token/secret/password/credential/
  recovery, а также бэкапы.
- Никогда не вставляйте ключи и токены в код, в переписку и в этот репозиторий.
- Если ключ (например, от ИИ или от GitHub) всё же попал в публичное место,
  его нужно **немедленно отозвать** и выпустить новый — удаления файла
  недостаточно.

## Ограничения

- Разбивка на страницы оценочная, номера листов могут немного отличаться от
  Word.
- Старый `.doc` без LibreOffice не читается.
